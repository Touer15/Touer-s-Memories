TOUER'S MEMORIES — Python local website (Version 4)

WHAT'S INCLUDED
- Your streetlamp night photograph as the full-page background.
- Continuous animated rain that keeps moving while scrolling.
- The earlier gaming screenshot gallery plus your latest Albion Online Corrupted Lair screenshot.
- A large six-card Best Friends section. Click a card to open a friend popup and then visit that Steam profile.
- Your original Steam profile popup.

FRIEND PHOTOS
The friend cards request current Steam avatars through the external unavatar Steam-avatar service while the website is online. If an avatar cannot be fetched, a large initial is shown instead. The cards and Steam links still work either way. One of the linked Steam profiles is private, so Steam may restrict some profile details.

RUN
1. Extract the ZIP.
2. Open the folder in PyCharm.
3. Run app.py with Python 3.
4. Visit http://127.0.0.1:8000 if it does not open automatically.
5. Press Ctrl+C in the terminal to stop the local server.

No extra Python packages are required.
